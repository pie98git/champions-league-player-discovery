# Champions League-Level Player Discovery

A data-driven football scouting project aimed at identifying players outside Champions League clubs with statistical profiles similar to players competing in the UEFA Champions League.

## Objective

The goal of this project is to help football clubs identify undervalued talent by comparing league performance metrics between UCL and non-UCL players.

## Tech Stack

- Python
- pandas
- scikit-learn
- Plotly
- Jupyter Notebook

## Planned Features

- Player similarity analysis
- Positional scouting
- Statistical profiling
- Interactive visualizations
- Recommendation engine
